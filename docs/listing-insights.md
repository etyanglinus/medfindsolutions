# Client listing insights

Specialist, facility, school and supplier dashboards include a shared visibility panel, 7/30/90 day filters, an interactive chart and a CSV download. Metrics are scoped to the signed-in account.

Tracking begins with this deployment. A metric counts at most once per session, listing and day. Directory appearances count profiles returned on the current directory page, not search-engine impressions or confirmed viewport exposure. Profile visits and outbound phone, WhatsApp and website clicks are separate metrics. Website clicks cannot confirm visits on another website. Existing historical profile-view and supplier analytics records remain intact.

Public page styles are unchanged; a nonvisual script tracks existing contact links. Tracking links expire after 12 hours and require a valid server signature. Own-account and admin activity are excluded.

Dashboard reminders flag missing profile details/images/documents, profiles last updated over 90 days ago, rejected or expired documents, documents expiring within 30 days, and subscriptions expiring within 30 days. These are dashboard prompts.

The inquiry manager supports new/contacted/closed statuses, filtering and pagination across all four provider types. Existing supplier quoted and school reviewed/replied history remains available. Inquiry access follows active subscription entitlements. Supplier status changes retain their existing history records.

Subscription insights show active plan benefits, available listing limits and usage, and renewal links. Payments remain Paystack-only.
